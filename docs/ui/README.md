# Mobile redesign concepts

These are visual-direction mockups for the planned mobile-first browser
overhaul. They are not implementation specifications and intentionally avoid
real recipe data and final interface copy.

- `mobile-home-concept.png` explores the home/search page: a warm recipe
  journal, card grid, and an icon-only create action.
- `mobile-recipe-detail-concept.png` explores the detail view: a photo-led meal
  timeline and a compact contextual action tray.
- `mobile-photo-actions-concept.png` focuses on the photo controls: choose as
  primary, edit a caption, download the original, and place destructive actions
  behind an overflow menu.

The implementation must retain native control semantics, visible focus, clear
accessible names, and 44 by 44 pixel minimum touch targets. The decorative
notebook motifs and generated navigation should be treated as inspiration only,
not required product features.
